# Publicação no Facebook

No editor de publicação, selecione Instagram, Facebook ou Instagram e Facebook. Para Facebook, escolha uma Página conectada. Publicações somente no Facebook não exigem conta do Instagram.

São aceitos imagem, reel e carrossel de imagens. Carrosséis com vídeos continuam disponíveis somente para Instagram. A seleção vale para rascunhos, agendamento e publicação imediata. Lotes mantêm o destino Instagram.

A conexão precisa da permissão `pages_manage_posts`, além das permissões de leitura já usadas. Reconecte o Facebook para conceder a permissão. Quando `FACEBOOK_CONFIG_ID` estiver configurado, inclua essa permissão na configuração de Login para Empresas na Meta.

Se uma rede publicar e a outra falhar, o identificador do envio concluído é preservado para as novas tentativas. Nesse caso, somente reagendamento é permitido, preservando conteúdo e destinos. Arquivos são removidos depois de concluir os destinos selecionados.

Referência do fluxo de reels: https://www.postman.com/meta/facebook/documentation/r56bjfd/facebook-api
